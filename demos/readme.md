# Demos

Interactive demos for CSC 212. Each demo is a single HTML file: download it, then open it in your web browser. You do not need to install anything, and the demos work without an internet connection. Each demo has a **How to use this demo** section at the top of the page.

| File | What it shows |
|---|---|
| `recursive-helpers.html` | Step-by-step trace of recursive helpers that return a pointer: list `remove_r`, BST `insert_helper`, and BST `remove_helper` |

## Option 1: download one file from GitHub

1. On GitHub, open the `demos` folder and click the file name, for example `recursive-helpers.html`.
2. GitHub shows the **source code** of the page, not the demo. This is expected.
3. Click the **Download raw file** button (the down-arrow icon at the top right of the code).
4. Find the file in your `Downloads` folder and double-click it. It opens in your default browser.

> [!WARNING]
> Do not right-click the file name and choose "Save Link As". That saves the GitHub page around the file, not the demo itself.

If the file does not open in a browser, check its name:

- it must end in `.html`, not `.html.txt` or `.txt`
- on Windows, turn on file extensions to see the full name: in File Explorer, choose **View > Show > File name extensions**
- you can also drag the file onto an open browser window

## Option 2: use your clone of the course repository

If you already cloned the repository, get the latest files and open the demo from the terminal.

```
$ cd 212-fall-2026
$ git pull
```

Then open the file:

- macOS: `$ open demos/recursive-helpers.html`
- Windows (PowerShell): `PS> start demos\recursive-helpers.html`
- Linux: `$ xdg-open demos/recursive-helpers.html`

Or double-click the file in your file manager.
