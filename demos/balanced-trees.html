2-3 trees and left-leaning red-black trees

A red-black tree is a 2-3 tree written as a BST: a red link glues two BST nodes into one 3-node. Insert is the plain BST insert, plus three local fixes on the way back up: rotate_left, rotate_right, flip_colors. Watch each fix in the red-black tree (top) and what it means in the 2-3 tree (bottom).

How to use this demo
  1. Type a key and click Insert, or click a preset under Try. The demo then shows the insert one step at a time.
  2. Step with Next and Prev, or with the Left and Right arrow keys. Play runs the steps on its own; the slider sets the speed. Last jumps to the end of the insert.
  3. Watch four things together:
    • Code: the highlighted line is the one running now
    • Red-black tree: the blue ring is the node p of the running call; orange rings mark the path from the root
    • 2-3 tree: the same tree with every red link glued; an orange dashed box is a temporary 4-node, which must split
    • What happened: the step, in red-black terms and in 2-3 terms
  4. Turn on Draw red links flat. The red-black tree moves into the shape of its 2-3 tree.
  5. Insert all inserts every key in the sequence box, without steps. Undo removes the last insert. Clear starts over.
  6. Compare the heights: the stats show the height a plain BST would have with the same insertion order.

Tip: before you click Next on the way back up, predict which of the three fixes will run at p, if any. Then check.
